Use it in a course

A deck needs one stylesheet and one script. Course name, track and day come from data attributes; the language and direction come from the html element.

<!doctype html>
<html lang="en">                       <!-- Arabic: <html lang="ar" dir="rtl"> -->
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Day 1 · My Course</title>
<link rel="icon" href="https://sdaiaacademy.github.io/slides/img/academy.svg">
<link rel="stylesheet" href="https://sdaiaacademy.github.io/slides/deck.css">
</head>
<body>
<div class="deck" data-course="My Course" data-track="ai-engineering" data-day="Day 1">
  <section class="slide title"> … </section>
  <section class="slide"> … <aside class="notes">…</aside></section>
</div>
<script src="https://sdaiaacademy.github.io/slides/deck.js"></script>
</body>
</html>

Always the latest

Link to https://sdaiaacademy.github.io/slides/…. Every push to main reaches every course within a minute or two.

Pinned to a release

When a course must not change, link to a tag through jsDelivr: https://cdn.jsdelivr.net/gh/SDAIAAcademy/slides@v1.0.0/deck.css. Move the pin when ready.

Course-building skill

The skill/ folder is a Claude Code skill for building a new Academy course: it researches the topic, checks overlap with the existing courses, proposes an outline in the Academy's format, then builds the repository (course page, decks, labs, README with sources) on this slide system. Install it with a junction or symlink into ~/.claude/skills/sdaia-course.
